# Day 5 – ESP32 Wi-Fi Connection

## 📌 Description

This project demonstrates how to connect an ESP32 board to a Wi-Fi network using the Arduino WiFi library.

The ESP32 connects to the Wi-Fi network and displays the connection status and assigned IP address through the Serial Monitor.

## 🛠️ Technologies Used

* ESP32
* Arduino IDE
* Wi-Fi
* Wokwi Simulator
* Arduino WiFi Library

## 🎯 Objective

* Connect ESP32 to a Wi-Fi network
* Check the Wi-Fi connection status
* Display the assigned IP address
* Understand basic ESP32 Wi-Fi functionality
